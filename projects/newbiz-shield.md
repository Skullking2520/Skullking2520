## 프로젝트와 역할

kt cloud TECH UP 생성형 AI 과정의 스미싱 탐지 팀 프로젝트입니다. 현준수는 **서브 PM과 모델 개발**을 맡았습니다.

| 구분 | 담당 내용 |
| --- | --- |
| 모델 개발 | 분류 모델의 오류분석·데이터 보완·재학습과 평가 관련 작업 |
| 일정 관리 | 모델 개발과 연동 작업의 진행 일정 관리 |
| 의견 조율 | 팀원 간 이해와 개발 방향이 다른 부분을 맞추는 소통 |

Encoder·Decoder·데이터·API·화면의 팀별 담당은 [팀 역할표](https://github.com/Skullking2520/kdt-ai-2-team3-advanced/blob/main/README.md#팀과-역할)에 구분돼 있습니다. 서브 PM으로 모델 개발 일정과 관련 영역의 의견을 조율했습니다.
